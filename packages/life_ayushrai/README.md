# life-ayushrai (Python)

Python client and CLI for https://life.ayushrai.site/.

```bash
pip install life-ayushrai
life-ayushrai ask "Who is Ayush Rai?"
life-ayushrai sandbox
```

Homepage and documentation point at life.ayushrai.site. Source: https://github.com/ayushrai-hub/LifeOS/tree/main/packages/life_ayushrai
