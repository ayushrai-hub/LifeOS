# Official agent skills for life.ayushrai.site

These skills teach agents how to use Ayush Rai's public knowledge site without inventing facts.

## Install (skills.sh)

```bash
npx skills add ayushrai-hub/LifeOS
```

List without installing:

```bash
npx skills add ayushrai-hub/LifeOS --list
```

## Skills

| Skill | When to use |
| --- | --- |
| `lookup-ayush-rai` | Who Ayush Rai is, roles, location |
| `find-projects-and-products` | Adaptive RAG, MailU, OpenAI-RLHF, Shiksha-Mitra, RevenueRoles |
| `contact-ayush-rai` | Published email, phone, Calendly, Cal.com, Topmate |
