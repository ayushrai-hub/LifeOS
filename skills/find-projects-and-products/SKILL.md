# Find projects and products

Use this skill when the user wants what Ayush Rai has built that is listed on https://life.ayushrai.site/.

## When to use

- The user asks for projects, repositories, or products.
- The user names Adaptive RAG, MailU, OpenAI-RLHF, Shiksha-Mitra, or RevenueRoles.

## Steps

1. Open https://life.ayushrai.site/sites/projects/ and https://life.ayushrai.site/sites/products/.
2. Prefer the live product URLs already printed on those pages.
3. If you call the API, use https://life.ayushrai.site/ask or the sandbox at https://life.ayushrai.site/api/v1/sandbox.
