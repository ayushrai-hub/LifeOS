Sandbox

Call GET /api/v1/sandbox to exercise the API without a token. The JSON body is the public profile and page list. The response header X-Sandbox: true marks the call. There is no separate private dataset, and the handler does not write, delete, or send messages.

Use the sandbox when you want a safe first request. Use auth.md only if you are practicing the 401 discovery flow against /api/v1. Both return public facts.
