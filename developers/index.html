Developers

Read the public site from a script. Nothing here writes data.

Quickstart

The site is a knowledge base, not a multi-tenant app. These calls return public facts about Ayush Rai.

curl -sS https://life.ayushrai.site/llms.txt
curl -sS -H 'Accept: text/markdown' https://life.ayushrai.site/
curl -sS 'https://life.ayushrai.site/ask?query=Who%20is%20Ayush%20Rai'
curl -sS https://life.ayushrai.site/api/v1/sandbox

Sandbox

The sandbox is /api/v1/sandbox. It needs no API key and no bearer token. The response is the same public catalog as the rest of the site, with the header X-Sandbox: true. It does not create records, send email, or touch a private dataset, because this site does not have one. A short explanation is on the sandbox page.

API

Documentation for agents starts at llms.txt and the OpenAPI document. The API catalog is at /.well-known/api-catalog. GET /ask/ answers a question. POST /api/v1/batch/ answers up to ten questions immediately. POST /api/v1/jobs/ returns 202 Accepted with a Location poll URL for the same read-only answers. Prefer trailing slashes on API paths. GET /api and GET /api/v1 return 401 with WWW-Authenticate until you follow auth.md. Errors are JSON with error.code, error.message, and links to docs. List responses accept page and limit. Responses advertise soft RateLimit-* headers (120 per 60 seconds). POST callers may send Idempotency-Key.

There is no private API key to provision. Anonymous registration at /agent/identity leads to a non-secret bearer, public-read, which only repeats the public pages. Use the sandbox when you want to skip that handshake. Public pricing is documented in pricing.md (everything listed there is free). Versioning and Sunset rules are on the deprecation policy page.

curl -sS -X POST https://life.ayushrai.site/api/v1/jobs/ \
  -H 'content-type: application/json' \
  -d '{"queries":["Who is Ayush Rai?","projects"]}'
