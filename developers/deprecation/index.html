API versioning and deprecation

How the public read API changes over time.

The current surface lives under /api/v1, plus unversioned helpers /ask and the MCP paths. The OpenAPI document at /openapi.json is the machine-readable contract.

Stability

Additive changes (new optional fields, new endpoints, new MCP tools) may ship without bumping the URL version. Removing or renaming a field, changing an auth challenge shape, or changing a required request field is a breaking change.

Deprecation

Before a breaking change ships, responses on the retiring path carry Deprecation: true and a Sunset HTTP date at least 30 days out. The replacement path is documented here and in llms.txt. After the Sunset date the old path may return 410 Gone with a link to the replacement.

Current notice

No endpoints are deprecated today. /mcp/knowledge is an alias of the product MCP at /mcp/product and will remain available.
