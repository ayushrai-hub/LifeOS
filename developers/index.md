# Developers

Read the public site from a script. Start with https://life.ayushrai.site/llms.txt and https://life.ayushrai.site/openapi.json.

The sandbox is `GET /api/v1/sandbox`. It needs no token and writes nothing. Protected paths return 401 until you follow https://life.ayushrai.site/auth.md.

Source: https://github.com/ayushrai-hub/LifeOS
