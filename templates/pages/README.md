# Page templates

Copy a file from this folder when creating a new page. Replace `{{TOKENS}}` and `[PLACEHOLDER: …]` with real content only when known.

| Template | Use |
|----------|-----|
| `site-home.html` | Subdomain / site homepage |
| `portfolio-home.html` | Portfolio entry page |
| `project-case-study.html` | Project case study (required sections) |
| `blog-post.html` | Blog post |
| `research.html` | Research write-up |
| `book-notes.html` | Book notes |
| `talk.html` | Talk / speaking |
| `resume.html` | Resume |
| `experience.html` | Role / experience |
| `learning-notes.html` | Learning / working notes |
| `skill.html` | Skill evidence page |
| `technology.html` | Technology page |
| `company.html` | Company hub |
| `timeline-event.html` | Timeline node |
| `achievement.html` | Achievement with evidence |
| `failure.html` | Failure / lesson |
| `experiment.html` | Experiment log |

Partials live in `/includes` and `/templates/partials`.
