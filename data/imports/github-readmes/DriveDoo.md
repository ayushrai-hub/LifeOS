## 🚀 Quick Start

### Prerequisites

- Git installed on your system
- Appropriate runtime environments for specific projects (Node.js, Python, etc.)

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ayushrai-hub/DriveDoo.git
   cd DriveDooWindows
   ```

2. **Explore projects:**
   ```bash
   # List all projects
   ls -la
   
   # View project documentation
   cat docs/project-index.md
   ```

3. **Run specific projects:**
   ```bash
   # Example: Run a React project
   cd egrahok-web
   npm install
   npm start
   
   # Example: Run a Python project
   cd Agents
   python agent.py
   ```
