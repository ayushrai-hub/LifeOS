# Longevity operating guide

This knowledge base is meant to outlast any single website theme.

## Non-negotiables

1. **Add entities; do not fashionably rename folders.** Archive with `status: archived` + `supersedes` edges.
2. **One fact, one place.** Reference `id`s; never copy biography into HTML.
3. **Evidence over titles.** Impact, stages, and claims need artifacts or honest “unknown.”
4. **Growing personality, not a frozen brand.** Philosophy and thinking notes are expected to change.

## Where new life goes

| Life event | Primary folder | Also link |
|------------|----------------|-----------|
| Job / role | `career/experience/` | `companies/`, `timeline/career-events/` |
| School / program | `career/education/` | `organizations/`, timeline |
| Community joined | `communities/` | events, impact |
| Hackathon / meetup / conference | `events/` | `timeline/`, media, speaking |
| Talk given | `speaking/talks/` or `engagements/` | domains, impact |
| Article / essay | `writing/` | domains, projects |
| Course finished | `learning/courses/` | `certifications/` if credentialed |
| Credential earned | `certifications/` | media/certificates, timeline |
| Product shipped | `products/` + `projects/` | impact evidence |
| Idea / bet | `ideas/` | market-lens note |
| Experiment | `experiments/` | research if formal |
| Trip that changed you | `travel/` | timeline, gallery |
| Fitness milestone | `fitness/milestones/` | logs, photos |
| Photo worth keeping | `media/photos/` + optional `gallery/` | event, people, timeline |
| Hard lesson | `reflections/` | principles if durable |
| Goal | `goals/` | person/goals.md summary only |

## Decades rule

Prefer **many small dated files** over rewriting one mega-page. Indexes (`_index.yaml`) list; entities hold truth.

## Growth themes to keep feeding

- Public speaking & storytelling → `speaking/` + `domains/public-speaking|storytelling`
- Market understanding → `thinking/market-lens.md` + dated notes
- Geopolitics → `thinking/geopolitics-lens.md` + dated notes
- Courses & certifications → inbox → full entities with proof
