# Domains

Fields of active work and study. Distinct from `learning/domains/` (evidence stages). This folder holds durable domain identities; learning domains track current stage and proof.

## How to add

Copy `templates/domain.md`. Cross-link `learning.domain.*` when stage evidence exists.

- Template: `knowledge/templates/domain.md`
- Entity type: `domain`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
