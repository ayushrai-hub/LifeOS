# Thinking

Working notes on how ideas form: market lenses, geopolitics, systems, product judgment. Evolving, dated.

## How to add

Add dated notes from `templates/thinking-note.md`. Promote durable beliefs into `principles/`.

- Template: `knowledge/templates/thinking-note.md`
- Entity type: `thinking_note`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
