# Impact

Evidence of impact: people helped, products shipped, time saved, OSS, teaching, volunteer, research, writing, speaking. No title-as-impact.

## How to add

Add evidence records under `evidence/` from `templates/impact.md`.

- Template: `knowledge/templates/impact.md`
- Entity type: `impact`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
