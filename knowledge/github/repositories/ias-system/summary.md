## Short factual summary
AI-assisted audit system for Indian court judgments and police case files: OCR, SOP checks, LangGraph pipeline, FastAPI.

## Primary purpose
Identify compliance gaps and acquittal risks in legal/police case documents.

## Problem solved
Manual review of judgments/case files is slow; needs OCR + structured SOP scoring + audit trail.
