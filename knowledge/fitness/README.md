# Fitness

Long-term fitness timeline: weight, measurements, gym, strength, nutrition, running, MMA, health metrics, philosophy, goals.

## How to add

Log entries under `logs/`; milestones under `milestones/`; progress photos as media entities linked here.

- Template: `knowledge/templates/fitness-log.md`
- Entity type: `fitness_log`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
