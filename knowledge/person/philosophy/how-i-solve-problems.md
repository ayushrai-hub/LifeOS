# How I Solve Problems

## Pattern

1. Restate the problem in one sentence.
2. List constraints (time, risk, data, users).
3. Generate 2–3 approaches; pick a probe.
4. Instrument the probe.
5. Only then invest in the full solution.

## Growing edge

Better problem framing before coding; stronger postmortems.
