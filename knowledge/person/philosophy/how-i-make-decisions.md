# How I Make Decisions

Also see `person/decision-making.md`.

## Pattern

1. Name the decision and deadline.
2. List options and kill criteria.
3. Note reversibility (two-way vs one-way doors).
4. Choose the smallest experiment that reduces uncertainty.
5. Record the decision so I can audit myself later.

## Growing edge

Faster decisions on reversible work; slower, better notes on irreversible ones.
