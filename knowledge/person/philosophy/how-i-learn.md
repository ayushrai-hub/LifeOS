# How I Learn

I learn by shipping small systems, reading failure modes, and keeping evidence in this knowledge base.

## Operating pattern

1. Pick a real problem (project or question).
2. Build the smallest working slice.
3. Measure or describe what broke.
4. Write a note before the memory fades.
5. Upgrade stage only when evidence exists (`learning/stages.md`).

## What I refuse

- Confusing tutorials watched with skills practiced.
- Inflating titles or stages from keywords alone.
- Hoarding private demos with no writeup.

## Growing edge

Stronger evaluation harnesses, slower reading with notes, and teaching as a forcing function.
