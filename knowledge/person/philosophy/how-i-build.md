# How I Build

Build for change. Prefer clear boundaries, boring reliability, and case studies that admit tradeoffs.

## Habits

- Start with the user path, then the architecture.
- Separate deterministic logic from generative components when risk matters.
- Leave a project entity that a future me (or an AI consumer) can trust.

## Growing edge

Instrumentation, production operations, and killing ideas that only look clever.
