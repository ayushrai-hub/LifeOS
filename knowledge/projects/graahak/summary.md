# Graahak; short summary

**Repo:** https://github.com/ayushrai-hub/graahak  

**What it is:** A React + TypeScript + Vite + Tailwind frontend with three screens for coupon screenshot upload, field verification, and a USE/SKIP-style result. The in-app product name is **TruthPrice**.

**What it is not:** A documented product, a working analysis/OCR/backend system, or a deployed app. README is one word. Results and “extracted” coupon fields are hardcoded. `@supabase/supabase-js` is unused in source.

**History:** Created 2026-01-01; two commits; sole author Ayush Rai; Bolt (`bolt-vite-react-ts`) scaffolding present.

**Showcase:** Do not present as a finished case study. Optional as an early UI prototype only if framed with those limits.
