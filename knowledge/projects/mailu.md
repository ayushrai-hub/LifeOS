# MailU

## Problem

Email search is keyword-bound; cloud AI over personal mail raises privacy concerns. MailU keeps intelligence local.

## Features

- Gmail ingestion
- OAuth authentication
- Semantic search
- Local RAG
- Email analytics
- Email categorization
- Report generation

## Technology

- FastAPI
- SQLite
- ChromaDB
- Docker
- Ollama

## Skills demonstrated

- OAuth
- ETL
- Vector search

- Privacy-first AI
