# Adaptive RAG

## Problem

Fixed RAG pipelines fail when a query needs indexed documents, general knowledge, or live web search. The system routes intelligently among retrieval, web search, and LLM reasoning.

## Built

- LangGraph workflow
- FastAPI backend
- Qdrant vector search
- MongoDB memory
- Query rewriting
- Relevance grading
- Search fallback
- Multi-stage routing

## Skills demonstrated

- Agentic AI
- LangGraph
- Retrieval
- Vector databases
- Production APIs
