# Companies

Organizations Ayush has worked with, for, or beside. Prefer `company.*` here; schools and societies often live in `organizations/`.

## How to add

Copy `templates/company.md` → `companies/<slug>.md`. Link from `experience.*` via `company_id`.

- Entity type: `company`
- One entity per file
- Do not invent metrics or headcount
