# Media

Canonical binary assets with metadata entities.

| Kind | Path | Entity type |
|------|------|-------------|
| Photos | `photos/` | `photo` |
| Videos | `videos/` | `video` |
| Certificates | `certificates/` | media + link from `certification` |
| Slides | `slides/` | `slides` |
| Presentations | `presentations/` | `presentation` |
| Diagrams | `diagrams/` | `diagram` |
| Documents / PDFs | `documents/` | `document` |
| Design files | `design/` | `design_asset` |

Every media file needs a sibling or companion entity with: date, location, people, description, related project/community/event/timeline/blog.

Galleries assemble photos; they do not replace photo entities.
