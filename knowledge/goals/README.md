# Goals

Dated goals across life domains. Person-level goals also live in `person/goals.md`; this folder holds granular goal entities.

## How to add

Copy `templates/goal.md`. Review quarterly; archive completed.

- Template: `knowledge/templates/goal.md`
- Entity type: `goal`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
