# Communities

Every community Ayush participates in; developer groups, open source, AI circles, startups, research groups, hackathons, college clubs, NGOs, meetups, conferences.

## How to add

Copy `templates/community.md` into this folder as `<slug>.md`. Fill why joined, contributions, learning, people, events, talks, photos, impact, related projects/skills.

- Template: `knowledge/templates/community.md`
- Entity type: `community`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
