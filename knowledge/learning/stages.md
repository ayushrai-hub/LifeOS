# Learning stage definitions

Use these labels on every topic. Do not upgrade a stage without new evidence.

| Stage | Meaning | Minimum evidence |
|-------|---------|------------------|
| **Exploring** | Reading / skimming / forking / naming interest | Mentions, forks, thin notes, bio keywords alone |
| **Learning** | Structured study with artifacts | Courses, curricula drafts, notes, tutorials completed with output |
| **Practicing** | Repeated hands-on work | Multiple commits/repos, prototypes, unfinished systems |
| **Applying** | Used to solve a concrete problem with a shippable artifact | Project README + runnable path + problem statement |
| **Teaching** | Explains to others with durable materials | Curriculum repos, tutorials, talks (verified) |
| **Expert-level experience** | Sustained production ownership, peer recognition, or measured outcomes | Employment proof, production metrics, publications, sustained maintainer role; **none claimed in this ingest without that evidence** |

## Rules

1. Bio text is a **claim**, not stage proof.
2. Aspirational curriculum language (e.g. “Staff-level”, “industry-leading”) does **not** move a stage upward.
3. Building a project = at most **Applying** for that stack slice, not Expert.
4. Missing sources (resume, LinkedIn, certificates) leave many topics under-specified; prefer lower stage.
