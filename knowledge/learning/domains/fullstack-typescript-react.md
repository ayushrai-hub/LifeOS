# Full-stack TypeScript and React

## What is it?

Building web product UIs (and sometimes accompanying APIs) with React, TypeScript, modern bundlers (Vite), and component systems.

## Why it matters

Most product surfaces still ship as web apps; AI backends need operable UIs and marketing/trust sites need credible frontends.

## Evidence

Multiple TypeScript/React repos: WeCare, Shiksha-Mitra, ClubMe, Expert-O, navigator-tech, kyc frontend, Auto-Latex-resume (README missing), portfolio experiments.

## Stage

**Practicing.** Some READMEs are polished marketing; backend depth and production traffic unverified. Expert-O language is hype-heavy; do not treat as proof of marketplace expertise.

## Technologies

React 18/19, TypeScript, Vite, Tailwind, React Router, Radix/shadcn-style components, Framer Motion, Vitest/Jest (where listed), occasionally FastAPI/Node APIs in sibling projects.
