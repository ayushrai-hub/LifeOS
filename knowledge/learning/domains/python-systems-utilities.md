# Python systems utilities

## What is it?

CLIs and local tools that manipulate files, email, or host state with an emphasis on safety and reproducibility.

## Evidence

- FileU; stdlib-only organizer; dry-run; hash verify (1 star)
- MailU; email intelligence toolchain
- hiring_intellgence; Excel workbook builder CLI + tests
- Emailify; description only; README missing → **unverified**

## Stage

**Applying** for FileU/hiring tooling; MailU **Practicing/Applying** with caveats.

## Technologies

Python 3.10+, stdlib, openpyxl/pandas (hiring), Gmail API (MailU).

## Field anchors

- Python packaging/CLI patterns
- Cross-platform path and filesystem semantics
