# Courses

Completed and in-progress courses. Certifications with issuers also live in [`../../certifications/`](../../certifications/).

## How to add

1. Prefer `templates/course.md` → `learning/courses/<slug>.md`
2. If a formal credential was issued, also create `certifications/<slug>.md` and link `certificate_id` / media
3. Capture queue: [`../../certifications/inbox.md`](../../certifications/inbox.md)
4. Link `domain.*` and update learning stages only with evidence

## Index

See `_index.yaml` in this folder as courses are added.
