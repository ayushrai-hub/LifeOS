# Events

Hackathons, conferences, workshops, NGO work, meetups, speaking, volunteer programs; attendance and outcomes.

## How to add

Copy `templates/event.md`. Also add a `timeline_event` spine entry when the date matters historically.

- Template: `knowledge/templates/event.md`
- Entity type: `event`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
