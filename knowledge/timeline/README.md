# Timeline

Chronological spine of meaningful life and career events. Other domains attach here.

## How to add

Copy `templates/timeline-event.md`. Prefer linking to rich entities (project, event, travel) rather than duplicating detail.

- Template: `knowledge/templates/timeline-event.md`
- Entity type: `timeline_event`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
