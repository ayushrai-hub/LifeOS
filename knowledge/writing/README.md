# Writing

Everything published or drafted: articles, blogs, research notes, tutorials, essays, docs, opinion.

## How to add

Use `templates/article.md` (or subtype templates). Place under blogs/, essays/, tutorials/, notes/, documentation/, opinion/.

- Template: `knowledge/templates/article.md`
- Entity type: `article`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
