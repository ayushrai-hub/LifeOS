# Speaking

Public speaking, storytelling craft, engagements, talks, slides. Canonical home for speech-related entities.

## How to add

Talks in `talks/`; engagements in `engagements/`; craft notes in `storytelling/`. Legacy path `public-speaking/` redirects here.

- Template: `knowledge/templates/talk.md`
- Entity type: `talk`
- One entity per file; kebab-case slug
- Link related projects, skills, people, events, media by `id`
- Prefer evidence over claims

## Longevity

Add new files; do not rename folders. Archive superseded entities with `status: archived` and `supersedes` edges instead of deleting history.
