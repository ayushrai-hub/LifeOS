# Agents

This file is both the public agent note for https://life.ayushrai.site/agents.md and the repository guide for coding agents.

## Using the public site

Read https://life.ayushrai.site/llms.txt before calling anything. The homepage returns markdown when the request sends `Accept: text/markdown` or comes from a known AI crawler. `?mode=agent` returns JSON with endpoints and authentication. The sandbox is `GET /api/v1/sandbox/`. Prefer trailing slashes on API paths (`/ask/`, `/api/v1/jobs/`). `POST /api/v1/jobs/` returns `202` with a poll `Location`. Protected paths return 401 with `WWW-Authenticate` until you follow https://life.ayushrai.site/auth.md. Local agent checks: `npm run check:agent`. External discovery blockers are listed in `docs/EXTERNAL_DISCOVERY.md`.

## Editing this repository

LifeOS is Ayush Rai's personal knowledge base and the static site served at https://life.ayushrai.site/.

- `knowledge/` is the source of truth for facts. Prefer updating an entity there, then the generated HTML.
- `sites/` is the public HTML. The homepage is generated by `node scripts/build-home.js` from `knowledge/_system/homepage.yaml` and `knowledge/person/profile.yaml`.
- Agent discovery files (`llms.txt`, `auth.md`, `.well-known/`, `api/`) describe the public site. Keep them aligned with the pages.
- Do not invent metrics, audience sizes, street addresses, or employer impact claims.
- Do not use em dashes (U+2014). `npm run qa` fails on them.
- Do not commit `knowledge/github/repositories/expert-o/` or anything matching the secrets rules in `.gitignore`.
- Preview with `python3 -m http.server 3000`. Vercel serves this repository as static files plus the `api/` functions and `middleware.js`.
- After homepage edits, run `npm run build:home` and commit the generated `sites/www/index.html` and `index.md`. There is no Vercel build step that regenerates them.

Humans who open `/` get the homepage HTML (rewritten from `sites/www/`). `/sites/www` permanently redirects to `/`. Agents that send `Accept: text/markdown`, a known bot user agent, or `?mode=agent` get markdown or JSON instead.
