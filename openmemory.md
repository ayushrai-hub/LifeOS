# OpenMemory Guide

## Overview

Personal Knowledge Base (PKB) / LifeOS. Canonical facts live in `/knowledge`; `/sites` is a static HTML consumer. Local preview: `python3 -m http.server 3000` (preferred over `npm start` / `serve`, which can bind odd ports and 500 on directory URLs).

Owner-canonical professional profile (2026-07-24): **Ayush Rai**, Bhopal; roles AI Engineer / Applied AI Engineer / LLM & Evaluation Engineer. Tagline and SEO flow from `knowledge/person/profile.yaml` via `scripts/build-home.js`.

## Architecture

- **Source of truth:** `knowledge/` (YAML + Markdown entities)
- **Site shell:** `sites/**/index.html` + shared `styles/site.css`
- **Homepage build:** `scripts/build-home.js` ← `knowledge/_system/homepage.yaml` + `person/profile.yaml` → `sites/www/index.html` + `data/home.json`
- **Catalog build:** `npm run build:site` (PowerShell) for resumes/portfolios/domains
- **Agent surface:** root `llms.txt`, `auth.md`, `AGENTS.md`, `.well-known/*`, and `middleware.js`. Humans hitting `/` redirect to `/sites/www/`. `Accept: text/markdown`, known AI bot user agents, and `?mode=agent` are answered by middleware. Vercel `trailingSlash` is false so Markdown 404 probes without a trailing slash return 404 bodies on the first hop; directory URLs are normalized in middleware. `api/*.js` serves NLWeb `/ask`, sandbox, batch, async jobs (`202` + poll), product+docs MCP, and the 401 auth challenge. Soft `RateLimit-*` headers and typed OpenAPI schemas live with those handlers. SDK/CLI source: `packages/life-ayushrai`. External registry checklist: `docs/EXTERNAL_DISCOVERY.md`. `npm run check:agent` exercises the surface locally. Vercel `installCommand` is `npm install` because middleware imports `@vercel/functions`. Public GitHub source: `ayushrai-hub/LifeOS`.
- **Reading log build:** `npm run build:reading` ← `knowledge/reading/currently-reading.json` → `sites/currently-reading/index.html` (then rebuilds home). Vercel has no build step, so generated HTML is committed; CI runs `--check`
- **Experience:** `knowledge/career/experience/` (FoCDoT primary); unified RLHF/eval at `knowledge/career/expertise/rlhf-and-model-evaluation.md`
- **Flagship projects:** `knowledge/projects/{adaptive-rag,mailu,openai-rlhf}.md` + GitHub ingest under `knowledge/github/repositories/`
- **Products:** public SaaS (Shiksha-Mitra, RevenueRoles) plus AI-system product framing in `knowledge/products/`

## Components

- **Homepage (`sites/www`):** Wide shell (`.page.home`), photo + lede side-by-side (`.home-hero`), compact door nav (`.home-doors`), three useful panels (`.home-panels`: focus / latest / updated), colophon footer from `homepage.yaml`
- **Favicon:** `assets/icons/favicon.svg` (geometric A monogram, ink on paper); also mirrored at `/favicon.svg`; linked site-wide via `<link rel="icon">`
- **Site chrome:** Fixed top-right B/W theme toggle (`scripts/site-chrome.js`, styles in `site.css`)
- **Inner pages:** Narrower reading measure (`--measure` ~48rem), document aesthetic (Georgia, blue links, no cards)
- **AI resume:** `sites/career/resumes/ai.html` filled from canonical FoCDoT / Outlier / flagship projects
- **Currently Reading (`sites/currently-reading`):** Generated by `scripts/build-reading.js` (validates types/statuses/dates/URLs, no em dashes). Sections: compact table + numbered entries, Finished archive, Learning topics, Built From Reading. Empty states until real entries exist. Styles are `.reading-*` in `site.css`; the table stacks below 560px. Schema + Instinct workflow in `knowledge/reading/README.md`
- **Static QA (`scripts/qa-site.js`):** `npm run qa`, Node with no dependencies. Fails on any em dash (U+2014 or its HTML entity) in non-ignored text files (file list from `git ls-files`, so `.gitignore` applies), missing viewport meta, or missing catalog pages. `qa-site.ps1` only wraps it

## Patterns

- Minimal document UI; denser vertical rhythm; use width for lists/panels on home, keep prose measure readable
- No em dashes; evidence over marketing copy
- Prefer structured entities over resume keyword stuffing; merge similar content; do not invent metrics
- RLHF orgs (Scale AI, Outlier, Turing, Snorkel AI, Airdawgs Labs) → one expertise entity, not duplicated employment pages
- **Contact surfaces:** Booking (Calendly + Cal.com) and Support (Buy Me a Coffee) live on `sites/contact`; Topmate mentoring on Career + Contact; never homepage hero/CTA
- `knowledge/github/repositories/expert-o/` is a gitignored local clone (nested `.git`, `node_modules`, `.env.local`); never commit or edit it
