# OpenMemory Guide

## Overview

Personal Knowledge Base (PKB) / LifeOS. Canonical facts live in `/knowledge`; `/sites` is a static HTML consumer. Local preview: `python3 -m http.server 3000` (preferred over `npm start` / `serve`, which can bind odd ports and 500 on directory URLs).

Owner-canonical professional profile (2026-07-24): **Ayush Rai**, Bhopal; roles AI Engineer / Applied AI Engineer / LLM & Evaluation Engineer. Tagline and SEO flow from `knowledge/person/profile.yaml` via `scripts/build-home.js`.

## Architecture

- **Source of truth:** `knowledge/` (YAML + Markdown entities)
- **Site shell:** `sites/**/index.html` + shared `styles/site.css`
- **Homepage build:** `scripts/build-home.js` ← `knowledge/_system/homepage.yaml` + `person/profile.yaml` → `sites/www/index.html` + `data/home.json`
- **Catalog build:** `npm run build:site` (PowerShell) for resumes/portfolios/domains
- **Agent surface:** root `llms.txt`, `AGENTS.md`, `.well-known/*`, `middleware.js`, and `discovery/` (auth.md, openapi.json, pricing.md, skills.md, llms-full.txt, etc., served at root URLs through `vercel.json` rewrites; root `/index.md` rewrites to `sites/www/index.md`). Humans hitting `/` get homepage HTML (rewrite from `sites/www/`); `/sites/www` 308s to `/`. `Accept: text/markdown`, known AI bot user agents, and `?mode=agent` are answered by middleware. Vercel `trailingSlash` is false so Markdown 404 probes without a trailing slash return 404 bodies on the first hop; directory URLs are normalized in middleware. `api/*.js` serves NLWeb `/ask`, sandbox, batch, async jobs (`202` + poll), product+docs MCP, and the 401 auth challenge. Soft `RateLimit-*` headers and typed OpenAPI schemas live with those handlers. SDK/CLI source: `packages/life-ayushrai` (npm) and `packages/life_ayushrai` (PyPI clients; not deployable services). External registry checklist: `docs/EXTERNAL_DISCOVERY.md`. `npm run check:agent` exercises the surface locally. Vercel `installCommand` is `npm install` because middleware imports `@vercel/functions`. Public GitHub source: `ayushrai-hub/LifeOS`.
- **Vercel deploy:** single project (no `services` key). Team `ayush-rais-work22` / project `life-os`. Middleware is Edge-only negotiation (home rewrite, markdown/agent Accept, alias 308s, trailing-slash rewrite). It must not `fetch()` the same origin (Node runtime re-enters middleware and yields `MIDDLEWARE_INVOCATION_FAILED`). HTML misses use root `404.html`. Unknown `/api/v1/*`, `/v1/*`, `/v2/*` rewrite to `api/not-found`. `.vercelignore` excludes import snapshots, local Expert-O clone, and heavy reports.
- **API conventions:** all handlers parse bodies through `agent/http.js` `readJson` (guards Vercel's throwing `req.body` getter) and emit `errorBody(code, message, status, hint)`. `/oauth/register` is RFC 7591 public-client registration. `agent/negotiate.mjs` owns alias-host 308s (`aliasRedirect`) and RFC 9745 headers for deprecated `/v1/*` aliases (`deprecationHeaders`), applied in `middleware.js`.
- **Reading log build:** `npm run build:reading` ← `knowledge/reading/currently-reading.json` → `sites/currently-reading/index.html` (then rebuilds home). Vercel has no build step, so generated HTML is committed; CI runs `--check`
- **SEO build:** `npm run build:seo` runs `scripts/seo/*` against `config/seo-pages.json`, rebuilds reading/home/sitemap, and snapshots research `<main>` hashes to `data/seo/research-integrity.json`. `npm run check:seo` enforces unique titles, canonicals, sitemap coverage, and research integrity. Canonical homepage is `/`; middleware 308s `/sites/www` → `/`. Homepage links are root-absolute `/sites/...` so they work when served at `/`.
- **Experience:** `knowledge/career/experience/` (FoCDoT primary); unified RLHF/eval at `knowledge/career/expertise/rlhf-and-model-evaluation.md`
- **Flagship projects:** `knowledge/projects/{adaptive-rag,mailu,openai-rlhf}.md` + GitHub ingest under `knowledge/github/repositories/`
- **Products:** public SaaS (Shiksha-Mitra, RevenueRoles) plus AI-system product framing in `knowledge/products/`

## Components

- **Homepage (`sites/www`):** Wide shell (`.page.home`), photo + lede side-by-side (`.home-hero`), compact door nav (`.home-doors`), three useful panels (`.home-panels`: focus / latest / updated), colophon footer from `homepage.yaml`
- **Favicon:** `assets/icons/favicon.svg` (geometric A monogram, ink on paper); also mirrored at `/favicon.svg`; linked site-wide via `<link rel="icon">`
- **Site chrome:** Fixed top-right B/W theme toggle (`scripts/site-chrome.js`, styles in `site.css`)
- **Inner pages:** Narrower reading measure (`--measure` ~48rem), document aesthetic (Georgia, blue links, no cards)
- **AI resume:** `sites/career/resumes/ai.html` filled from canonical FoCDoT / Outlier / flagship projects
- **Currently Reading (`sites/currently-reading`):** Generated by `scripts/build-reading.js` (validates types/statuses/dates/URLs, no em dashes). Sections: compact table + numbered entries, Finished archive, Learning topics, Built From Reading. Empty states until real entries exist. Styles are `.reading-*` in `site.css`; the table stacks below 560px. Schema + Instinct workflow in `knowledge/reading/README.md`
- **Vercel Web Analytics:** Static site, so no `@vercel/analytics/next`; every served page carries `<script defer src="/_vercel/insights/script.js"></script>` before `</head>`. Generators (`build-home.js`, `build-reading.js`, `build-site.ps1`) emit it; `npm run build:analytics` injects it into other pages (idempotent), `npm run check:analytics` verifies. `agent/mode.html` is excluded. `middleware.js` matcher skips `_vercel/`
- **Collections (`scripts/build-collections.js`):** `npm run build:collections` / `check:collections` (CI: `.github/workflows/collections.yml`). JSON in `knowledge/work/work.json`, `knowledge/books/books.json`, `knowledge/influences/people.json` → `sites/work`, `sites/books`, `sites/influences`. Validates ids, statuses, categories, URLs, em dashes; people need `sources`; book `changedApproach` needs `confirmedByOwner`. Shared shell emits breadcrumb nav (`nav.section-label`) + BreadcrumbList JSON-LD. Schemas in each folder's README
- **Life sections (2026-10-25):** `/about` is the hub with an "Explore" site map; `/about/story` (Seoni, family move for English-medium schooling, Jungle Book note, education, draft "Questions I keep returning to"); `/sites/work/public-policy` (GCTP 2025, owner facts only, `knowledge/events/gctp-2025.md`); `/sites/interests` (fitness, travel, reading, writing, ongoing book + long-running app). Homepage doors gained only `about` and `work`. Role proof of work (9 pages: www.ayushrai.site/pow/{ai-benchmark,agentic-ai,fde,ai-research-engineering,founding-engineer,devops-engineer,ml-engineer,product-management} and /gtm) is canonical on the main site; URLs live only in `work.json` `pow`, rendered as `/sites/work#proof-of-work` and per-entry "Proof of work" links (entry `pow` field). Hand-written pages link to that anchor. How-to: `docs/workflows/ADDING_LIFE_CONTENT.md`; owner questions: `docs/OWNER_INTAKE.md` section 13
- **Static QA (`scripts/qa-site.js`):** `npm run qa`, Node with no dependencies. Fails on any em dash (U+2014 or its HTML entity) in non-ignored text files (file list from `git ls-files`, so `.gitignore` applies), missing viewport meta, or missing catalog pages. `qa-site.ps1` only wraps it

## Patterns

- Minimal document UI; denser vertical rhythm; use width for lists/panels on home, keep prose measure readable
- No em dashes; evidence over marketing copy
- Prefer structured entities over resume keyword stuffing; merge similar content; do not invent metrics
- RLHF orgs (Scale AI, Outlier, Turing, Snorkel AI, Airdawgs Labs) → one expertise entity, not duplicated employment pages
- **Contact surfaces:** Booking (Calendly + Cal.com) and Support (Buy Me a Coffee) live on `sites/contact`; Topmate mentoring on Career + Contact; never homepage hero/CTA
- New pages: root-absolute links only (relative `../` links resolve wrongly on slashless clean URLs like `/sites/fitness`)
- Hometown spelling: publish "Seoni" (official; owner writes "Shivni", locals say "Sivni"). Kanha is not in Seoni district; phrase forest links carefully. Never expand "GCTP" without owner confirmation
- Internal-only fragments live in `templates/{components,includes,partials,pages}`; orank scan reports in `docs/reports/orank/`. All website pages live under `sites/` (including about, developers, guides, privacy, reference, sandbox, feeds) and discovery docs under `discovery/` (including section-llms), served at public URLs via rewrites in `vercel.json`.
- `knowledge/github/repositories/expert-o/` is a gitignored local clone (nested `.git`, `node_modules`, `.env.local`); never commit or edit it
