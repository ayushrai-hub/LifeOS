# Content Review Checklist

For a second pass (future-you or a reviewer).

## Truth

- [ ] Every factual claim is sourced or personally verified
- [ ] Metrics include definition (what, when, how measured)
- [ ] Team credit is fair; personal role is clear
- [ ] No confidential employer material

## Clarity

- [ ] Problem statement is understandable without insider jargon *or* jargon is defined
- [ ] Constraints are explicit
- [ ] Tradeoffs are real (not fake balance)
- [ ] Lessons are specific enough to use later

## Completeness vs honesty

- [ ] Missing sections are placeholders, not silently omitted when required by template
- [ ] Draft quality is labeled if unfinished
- [ ] Screenshots (if any) match the text and are annotated lightly if needed

## Graph

- [ ] Related projects / notes / books linked
- [ ] Bidirectional links added when both pages benefit
- [ ] Dead links checked

## Brand / IA

- [ ] Does not expose global navigation of everything
- [ ] Matches design principles (no cardifying content)
- [ ] Fits the correct site / portfolio

## Ship decision

- [ ] Publish
- [ ] Publish unlisted
- [ ] Return to draft with notes
