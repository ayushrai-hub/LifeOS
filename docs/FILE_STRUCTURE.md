# File structure

## Repository map

```
/
├── knowledge/           # SINGLE SOURCE OF TRUTH
│   ├── person/          # profile + narratives + philosophy
│   ├── career/          # education, experience, roles
│   ├── projects/        # project entities + case studies
│   ├── research/        # papers, experiments, findings
│   ├── writing/         # essays, blogs, notes
│   ├── books/           # reading list + notes
│   ├── learning/        # stages, domains, evidence
│   ├── certifications/  # credential entities
│   ├── media/           # photos, videos, diagrams, sources
│   ├── social|contact|business/
│   ├── github/          # ingested repos + reports
│   ├── metadata/        # schemas + indexes
│   ├── relationships/   # edges
│   ├── templates/       # blank entity shapes
│   ├── _system/         # homepage contract, site-status
│   ├── inbox|review|archive/
│   └── assets/documents # PDFs and exports
├── data/
│   ├── site-catalog.json
│   ├── home.json
│   ├── published.json
│   ├── seo/             # generated SEO integrity snapshots
│   └── imports/         # provenance (GitHub, identity, site crawl)
├── sites/               # static HTML
│   ├── www/             # homepage (served at /; /sites/www 308 → /)
│   ├── migrated/        # ayushrai.site extraction (unlinked)
│   ├── portfolios/      # catalog-generated
│   ├── domains/         # catalog-generated
│   ├── career/resumes/
│   └── …topic hubs
├── styles/
│   ├── site.css         # CANONICAL stylesheet
│   └── main.css         # compatibility alias (@import site.css)
├── scripts/
│   ├── build-site.ps1
│   ├── build-home.js
│   ├── build-reading.js
│   ├── seo/             # apply-meta, build-sitemap, check, write-integrity
│   ├── migrate-ayushrai-site.ps1
│   ├── qa-site.js       # npm run qa (qa-site.ps1 wraps it)
│   ├── site-chrome.js   # theme toggle (progressive enhancement)
│   ├── live-clock.js    # optional; not wired
│   └── knowledge/       # validate + import
├── templates/pages/     # HTML starters
├── includes/            # optional fragments (not SSI'd yet)
├── components/          # optional fragments
├── assets/images/       # web media
├── config/              # site.json / site.yaml / seo-pages.json
├── docs/                # this tree
├── package.json
├── vercel.json
├── sitemap.xml          # generated by scripts/seo/build-sitemap.js
└── index.html           # legacy stub; canonical home is / via middleware
```

## Ownership rules

| Path | May contain | Must not |
|------|-------------|----------|
| `knowledge/` | Facts, evidence, IDs | Presentation-only CSS hacks |
| `sites/` | HTML presentation | Duplicate facts without knowledge refs |
| `styles/` | CSS only | Business content |
| `data/imports/` | Read-only provenance | Edited “truth” without re-import |
| `sites/migrated/` | Staging HTML from external site | Homepage navigation links |

## CSS

Only `styles/site.css` is loaded by live pages. Modular `styles/base|components|layouts|themes` trees were removed as unused duplicates.
