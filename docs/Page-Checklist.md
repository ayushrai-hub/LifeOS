# Page Checklist

Use before publishing any page.

## Structure

- [ ] Correct template for page type
- [ ] Single `h1`
- [ ] Logical heading hierarchy
- [ ] Sections match the template contract (especially case studies)
- [ ] Placeholders only where facts are genuinely missing
- [ ] No invented content

## Writing

- [ ] Every sentence earns its place
- [ ] Claims replaced with evidence where possible
- [ ] No banned fluff / buzzwords
- [ ] Voice matches [Voice-and-Tone.md](./Voice-and-Tone.md)
- [ ] Failures/tradeoffs included when relevant

## Links

- [ ] Contextual links to related pages
- [ ] No orphaning of important references
- [ ] Link text is descriptive
- [ ] Visibility tier respected (not illegally promoted to root)

## SEO / meta

- [ ] `title`
- [ ] `meta description`
- [ ] canonical URL
- [ ] Open Graph tags
- [ ] Twitter tags
- [ ] JSON-LD if applicable
- [ ] `noindex` if draft

## Accessibility

- [ ] `lang` on html
- [ ] Meaningful alt text or none
- [ ] Focus visible
- [ ] Contrast OK
- [ ] Skip link present on long layouts

## Performance

- [ ] No unnecessary JS
- [ ] Images compressed / sized appropriately
- [ ] CSS via shared sheets only

## Final

- [ ] Reads as a document, not a brochure
- [ ] Would a skeptical peer trust this page?
