# Brand

## Positioning

A polymath’s public knowledge system.

Not “software engineer personal brand.”
Not “AI influencer site.”
Not a startup landing page.

The brand communicates breadth **through evidence across domains**, never through a slogan claiming greatness.

## Brand promise

If you read here, you get:

- primary sources about the work
- clear thinking artifacts
- durable notes and case studies
- minimal noise

## Brand expression

| Element | Expression |
|---------|------------|
| Name | Plain text, prominent but not billboard |
| Mark | Optional simple text wordmark; no mascot required |
| Color | Near-black on near-white; one quiet accent max (links) |
| Type | Serious, readable, timeless |
| Motion | Essentially none |
| Imagery | Real artifacts only (diagrams you made, screenshots of your work) |

## Domains of proof (not labels to boast)

Engineering, AI, ML, distributed systems, backend, frontend, data, leadership, management, product thinking, research, writing, communication, decision making, business, systems thinking, psychology, learning, teaching, career, life.

These appear as **sites, pages, and evidence**, not as a skills firework list on the homepage.

## Voice = brand

See [Voice-and-Tone.md](./Voice-and-Tone.md). The writing *is* the brand.

## What would break the brand

- Hype adjectives
- Fake metrics
- Stock photography
- Theme-park UI
- Exposing everything in a menu
- Claiming polymath status in a headline instead of showing the shelves of work
