# Voice and Tone (Knowledge Base)

This document governs **knowledge content**. For website chrome specifics, see also [Voice-and-Tone.md](./Voice-and-Tone.md).

## Voice (stable)

- Precise
- Calm
- Curious
- Evidence-oriented
- Willing to admit uncertainty and failure
- Allergic to hype

Sounds like a careful practitioner writing for careful readers; not a personal brand coach.

## Tone by entity type

| Entity / surface | Tone |
|------------------|------|
| Biography | Factual, compact |
| Personal story | Human, still non-dramatic |
| Values / mission / vision | Operational, testable statements |
| Philosophies | Principles + examples |
| Case studies | Analytical, tradeoff-aware |
| Research | Cautious; claim vs hypothesis |
| Resume / experience | Scannable, metric-backed |
| Achievements | Evidence-first |
| Notes | Informal OK; dated; honest |
| Social/contact records | Neutral metadata; notes only as needed |

## Confidence calibration

| Situation | Language |
|-----------|----------|
| Measured result | Number + method |
| Belief, weak evidence | “I currently believe… because…” |
| Unknown | “I do not know yet.” / placeholder |
| Team work | Credit team; specify personal role |

## Personality without performance

Reveal thinking through decisions, failures, tradeoffs, and refusals; not through slogans.
