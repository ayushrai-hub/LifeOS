# Content Checklist

Per content type. Complete in addition to [QUALITY_CHECKLIST.md](./QUALITY_CHECKLIST.md).

## Person narratives

- [ ] Biography factual and dated where needed
- [ ] Values/mission/vision written as operating statements
- [ ] Philosophies include examples, not slogans
- [ ] No invented life events

## Skill

- [ ] Description clear
- [ ] Experience contextualized
- [ ] Current level defined on an explicit scale
- [ ] Evidence listed
- [ ] Related projects/technologies linked
- [ ] Future goals realistic

## Project

- [ ] Problem and background present
- [ ] Timeline / role / responsibilities present
- [ ] Architecture and tech stack present
- [ ] Challenges, tradeoffs, solutions present
- [ ] Metrics/results honest (or placeholders)
- [ ] Lessons and future improvements present
- [ ] Repo/demo/docs links if they exist
- [ ] Related skills/tech/articles linked

## Experience

- [ ] Company referenced by entity ID when possible
- [ ] Duration precise
- [ ] Achievements and projects referenced, not only pasted
- [ ] Impact/metrics evidence-based
- [ ] Lessons captured

## Achievement / Award / Certification

- [ ] Date and category set
- [ ] Evidence/links present
- [ ] Related projects/skills linked

## Article / Blog / Research

- [ ] Summary/description set
- [ ] Claims scoped
- [ ] References/relationships listed
- [ ] Publication date set

## Talk / Conference / Presentation

- [ ] Event, date, role (speaker/attendee) clear
- [ ] Slides/video linked if available
- [ ] Topics linked to skills/projects

## Timeline event

- [ ] `occurred_at` accurate
- [ ] Category set (life/career)
- [ ] Linked entities present

## Social / Contact / Business

- [ ] Platform, URL, username normalized
- [ ] Category, purpose, visibility, priority, status set
- [ ] Duplicates marked, not deleted
- [ ] `last_verified` if active
