# Developers

The developer portal is https://life.ayushrai.site/developers/. It documents the quickstart, the sandbox at `/api/v1/sandbox`, OpenAPI, and auth.md.

There is no private API key. Public reads use the sandbox with no token, or the bearer `public-read` after the flow in https://life.ayushrai.site/auth.md.
